---

## Architecture & Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Runtime:** React 19
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Brand Source of Truth:** `src/lib/brand.config.ts`

---

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run type check
npx tsc --noEmit

# Production build
npm run build

# Run linter
npm run lint
```
